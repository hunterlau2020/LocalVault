## 6.1 模块一：数据库创建、打开、保存、锁定与解锁

### 6.1.1 创建数据库
测试点：
- 使用合法参数创建数据库成功
- 主密码为空时不可创建
- 两次密码不一致时不可创建
- 自定义 KDF 参数时可创建
- 启用密钥文件时可创建
- 启用 FIDO2 时可创建
- 启用 FIDO2 时生成恢复密钥包

### 6.1.2 打开数据库
测试点：
- 使用正确主密码打开成功
- 错误主密码打开失败
- 文件损坏时打开失败
- 元数据损坏时进入修复/保护流程
- 启用 FIDO2 的数据库必须通过第二因子
- 启用密钥文件但未提供文件时失败

### 6.1.3 锁定/解锁
测试点：
- 手动锁定成功
- 空闲超时自动锁定
- 锁屏/休眠触发锁定
- 解锁后条目可见
- 锁定后敏感信息不可继续访问

### 6.1.4 保存
测试点：
- 条目修改后保存成功
- 保存失败不破坏原数据库
- 保存后再次打开数据一致

## 6.4 模块四：字段级变更检测与历史版本

### 6.4.1 changed_fields 计算
测试点：
- 仅改密码时 `changed_fields = {password}`
- 改密码和备注时字段集合正确
- 修改自定义字段时字段路径正确
- 无变化保存时不得产生伪变更

### 6.4.2 历史版本记录
测试点：
- 每次编辑都追加历史版本
- 冲突解决后历史版本正确保留
- 删除操作会产生历史记录
- 恢复操作会产生新版本

### 6.4.3 历史版本上限
测试点：
- 单条目历史达到 10 条后触发清理
- 最早的非冲突版本优先被清理
- 冲突源版本优先保留
- 历史版本不会被清理到 0

## 6.10 模块十：FIDO2 绑定、验证与恢复密钥包

### 6.10.1 FIDO2 绑定
测试点：
- Windows WebAuthn API 可正常绑定
- 外置 USB Key 可绑定
- Windows Hello 可绑定
- 取消绑定流程可回退

### 6.10.2 解锁
测试点：
- 启用 FIDO2 后必须主密码 + FIDO2
- 主密码正确但 FIDO2 失败时不得解锁
- FIDO2 成功但主密码错误时不得解锁

### 6.10.3 恢复密钥包生成
测试点：
- 启用 FIDO2 时生成恢复密钥包
- 默认 12 个单词
- 支持 12 / 24 校验规则
- 恢复密钥包不会默认明文保存到数据库旁边

### 6.10.4 恢复流程
测试点：
- FIDO2 丢失时可进入恢复流程
- 输入主密码 + 恢复密钥包后可恢复访问
- 恢复密钥包错误时恢复失败
- 恢复成功后状态为 `rebind_required`
- 恢复密钥包不直接解密数据库，只作为授权令牌
